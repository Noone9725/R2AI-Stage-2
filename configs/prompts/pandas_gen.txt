3. BẢNG BỊ NGẮT QUA NHIỀU TRANG: Nếu các DataFrame được ghi chú là các phần liên tiếp của cùng 1 bảng, BẮT BUỘC phải ghép lại trước: `df = pd.concat([df1, df2], ignore_index=True)` rồi mới lọc dữ liệu.
4. ĐƠN VỊ TÍNH VÀ LÀM TRÒN (IN-QUERY UNIT SCALING & ROUNDING):
   - Nếu câu hỏi hỏi "triệu đồng" và dữ liệu trong bảng là Đồng (VND, số >= 10^10 hoặc đơn vị vnd): Chia `1e6` -> `result = round(float(val) / 1e6, 2)`.
   - Nếu câu hỏi hỏi "tỷ đồng": Chia `1e9` -> `result = round(float(val) / 1e9, 2)`.
   - Nếu câu hỏi hỏi "nghìn đồng": Chia `1e3` -> `result = round(float(val) / 1e3, 2)`.
   - Nếu câu hỏi hỏi "cổ phiếu" / "cổ tức": Lấy số lượng cổ phiếu (nếu hỏi triệu/nghìn cổ phiếu thì chia 1e6/1e3 tương ứng, nếu hỏi số lượng cổ phiếu thô thì giữ nguyên).
   - Nếu câu hỏi hỏi "tỷ lệ %", "ROE", "ROA", "tăng trưởng", "biên lợi nhuận": Nhân `100.0` và làm tròn 2 chữ số: `result = round(float((val1 / val2) * 100.0), 2)`. Nếu bảng đã có sẵn cột tỷ lệ %, giữ nguyên giá trị trích xuất.
   - Nếu câu hỏi hỏi "năm nào..." (năm có chỉ số cao nhất/thấp nhất): Trích xuất giá trị năm dạng số thực: `result = float(max_year)` (ví dụ `2019.0`), tuyệt đối không chia hệ số tiền tệ.

Ví dụ 4: Truy vấn năm ("Vào năm nào công ty có biên lợi nhuận cao nhất?")
```python
years = [2018, 2019, 2020]
best_year = 2018
max_margin = -1e9
for y in years:
    rev = df1[(df1['year'] == y) & (df1['item'].str.contains('Doanh thu thuần', case=False, na=False))]
    pat = df1[(df1['year'] == y) & (df1['item'].str.contains('Lợi nhuận sau thuế', case=False, na=False))]
    if not rev.empty and not pat.empty and float(rev['value'].iloc[0]) > 0:
        margin = float(pat['value'].iloc[0]) / float(rev['value'].iloc[0])
        if margin > max_margin:
            max_margin = margin
            best_year = y
result = float(best_year)
```

Ví dụ 5: So sánh nhóm nhiều công ty (df1, df2, ..., dfN): tính trung vị và tỷ trọng
```python
import numpy as np
def get_val(df, kw):
    s = df[df['item'].str.contains(kw, case=False, na=False)]
    return float(s['value'].iloc[0]) if not s.empty else 0.0

invs = [get_val(df, 'Hàng tồn kho') for df in [df1, df2, df3, df4, df5]]
liabs = [get_val(df, 'Nợ ngắn hạn') for df in [df1, df2, df3, df4, df5]]
ratios = [inv / liab if liab != 0 else 0.0 for inv, liab in zip(invs, liabs)]

med = float(np.median(ratios))
top_liab = sum(l for r, l in zip(ratios, liabs) if r > med)
total_liab = sum(liabs)
result = round(float((top_liab / total_liab) * 100.0), 2) if total_liab != 0 else 0.0
```
